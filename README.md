# MAXAW FIELD KOREA

기존 [MAXAW FIELD](https://www.maxawfield.com/)의 한국어 쇼핑몰 프로젝트입니다.

## 구현 범위

- 한국어 반응형 스토어 / 카테고리 / 검색 / 상품 상세
- 장바구니, 상품 옵션, 재고 확인, 주문 접수
- 별도 관리자(`/admin`): 상품 등록·수정·삭제, 다중 이미지 업로드, 카테고리·가격·재고·노출·추천 관리
- 관리자 주문 목록과 처리 상태 관리
- PostgreSQL 기반 영속 데이터 저장, httpOnly 서명 관리자 세션, 주문 시 재고 원자적 차감

## 로컬 시작

Node.js 20 이상 권장.

```bash
npm install
cp .env.example .env.local
npm run dev
```

필수 환경 변수:

| 변수 | 설명 |
|---|---|
| `DATABASE_URL` | Neon 등 PostgreSQL 연결 문자열 (필수) |
| `ADMIN_PASSWORD` | 관리자 로그인 비밀번호, 12자 이상 (필수) |
| `SESSION_SECRET` | 서명용 임의 문자열, 32자 이상 (필수) |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob 이미지 업로드에 필요 |

- 홈: `/`
- 관리자: `/admin`
- 서버 API: `/api`

Vercel에 GitHub 저장소를 연결하고 환경변수를 등록하면 Next.js로 배포할 수 있습니다. 상품/주문 테이블은 첫 요청 시 생성됩니다.

## 현재 미연동 및 운영 전 체크 사항

1. **결제 PG 미연동**: 주문 접수까지만 지원합니다. 실제 결제 완료로 표기하지 않습니다.
2. **배송비·정책·사업자 정보**: 한국 실운영 정책 확정 후 입력 및 고지 필요.
3. **기존 원본 웹사이트의 모든 디자인과 세부 인터랙션 1:1 복제 완료 상태는 아님**: 원본 페이지를 기준으로 한 1차 구현이며 화면별 디자인 대조와 수정이 필요합니다.
4. **실서버 빌드 및 DB·업로드 통합 테스트**: 환경변수 및 배포 환경 연결 후 검증 필요.
5. 사용자 개인 정보 포함 주문 데이터 접근 통제 및 운영 보안 검토 필요.

기존 해외 쇼핑몰 및 상품 DB와 자동 동기화하지 않습니다. **한국 관리자에서 등록한 상품만** 표시됩니다.

## 주문 접수 및 결제링크 안내 방식

1. 고객이 상품을 선택해 주문서(성함·연락처·배송주소·요청사항)를 제출합니다.
2. 관리자는 `/admin` → 주문 관리에서 주문 내용을 확인합니다.
3. 담당자는 해당 주문의 HTTPS 결제링크를 저장하고 **안내문 복사**를 이용해 문자/상담 채널로 직접 전달합니다.
4. 실제로 발송한 뒤 **발송 완료 표시**를 눌러 관리 기록을 남깁니다. 이 버튼은 메시지 자체를 발송하지 않습니다.
5. 결제 입금 사실을 외부에서 확인한 후 관리자가 `입금확인` → `배송중` → `완료` 상태로 변경합니다.

**결제링크 자동발송, SMS/카카오톡 연동, 결제 결과 웹훅은 아직 구현되지 않았습니다.** 주문서 제출은 결제 승인 또는 입금 완료를 의미하지 않습니다. 고객 정보가 포함된 관리 페이지는 안전한 운영 환경에서 보호해야 합니다.
